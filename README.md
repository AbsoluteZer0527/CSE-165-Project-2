# CSE 165 Project 2 - Travel and Wayfinding 

A Unity VR project of a drone navigation training program using hand gesture input with the Meta Quest 2. The project provides an easy-to-use hand gesture input system for travel and an effective wayfinding system that allows users to navigate through any given set of waypoints.
